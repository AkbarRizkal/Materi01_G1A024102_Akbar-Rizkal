# GIS untuk Pemantauan Perubahan Garis Pantai

## Studi kasus
Studi kasus: membandingkan posisi garis pantai pada dua waktu untuk menandai area yang mengalami abrasi atau akresi. Data koordinat dalam contoh ini bersifat simulasi, bukan hasil pengukuran lapangan.

## Implementasi
Kode pada proyek ini menunjukkan penerapan konsep materi dalam skala mini. Data contoh disediakan di folder `data/`.

## Cara menjalankan
```bash
pip install -r requirements.txt
python main.py
```

## Interpretasi dan batasan
Gunakan hasil sebagai demonstrasi alur kerja. Untuk penerapan nyata, gunakan data yang dapat dipertanggungjawabkan, lakukan validasi, dan dokumentasikan asumsi serta keterbatasan.
